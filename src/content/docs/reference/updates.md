Relua tells you when a new version is out, and you decide when to install it.

## When Relua checks

Relua checks for updates when it starts and every 12 hours while it's open. It asks GitHub, where Relua releases are published. This check is the only time Relua uses the network.

When an update is available, a dot appears on the Settings gear.

## Install an update

The update control sits at the bottom of every Settings tab. Open Settings with the gear, or press <kbd>⌘</kbd><kbd>,</kbd> on Mac, <kbd>Ctrl</kbd><kbd>,</kbd> on Windows.

1. Choose **Check for updates**. If you're up to date, you see **No updates available.**
2. If there's a new version, choose **Update**. The button shows **Downloading NN%**, then **Verifying…**.
3. Choose **Restart to update** when it suits you.

Nothing downloads or restarts until you choose to. Before restarting, Relua saves your drafts, unfinished drawings, and settings.

If there's no automatic download for your computer, the button reads **View release** and opens the release page instead.

## On a Mac

Relua must be in your Applications folder to update itself. If it isn't, you see **Move Relua to Applications and open the installed app before updating.** Move it there, open it from Applications, and try again.

## If Relua can't reach GitHub

You see **Could not reach GitHub. Check your connection and try again.** Check that you're online, then choose **Retry**.
